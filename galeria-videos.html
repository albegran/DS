Design System UNAV

Galería de Vídeos

Lista de reproducción multimedia responsiva con protección CSS contra títulos excesivamente largos e integración nativa de Motion Tokens.

Análisis Funcional y Técnico

UX: Enmarcado Fijo

  • Visibilidad Continua: Los controles de navegación están anclados a los extremos (Arriba/Abajo o Izquierda/Derecha) envolviendo las miniaturas. El usuario nunca pierde los controles de vista al hacer scroll.
  • Responsividad Fluida: La estructura Flex muta de columna a fila según las Container Queries de forma automática y fluida.

Accesibilidad y Tipografía

  • Marcado SEO / GEO: Generación estructurada de VideoObject e ItemList mediante Javascript para facilitar el rastreo algorítmico.
  • Interlineado Normativo: Integración estricta de las clases .unav-lh-tight, snug y normal según las especificaciones tipográficas del DS.
