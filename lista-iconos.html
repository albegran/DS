Design System UNAV

Listas con Iconos

Componente para reemplazar las viñetas nativas y mejorar la escaneabilidad visual.

Análisis y Documentación Oficial

1.- Guía de Implementación

Uso de clase OOCSS: El componente requiere un contenedor padre .unav-listIcon que gestiona el espaciado interno del conjunto. Cada entrada debe ser un nodo .unav-listIconItem.

Iconografía: Cada elemento incluye .unav-listIconIcon, que garantiza el alineamiento vertical con el texto adyacente y aplica el color de la jerarquía tipográfica.

2.- Guía Técnica

Construcción: Lista no ordenada semántica (<ul>) con listado de elementos (<li>).

Gestión Cromática: Los iconos inyectan el color a través de la propiedad color: inherit, lo que permite modificar el matiz de todo el bloque simplemente inyectando una clase de color sobre el elemento padre.

3.- Accesibilidad (A11y)

Blindaje: Al ser iconos ornamentales que complementan el texto de la lista, es obligatorio incluir el atributo aria-hidden="true" en el nodo del icono para evitar lecturas redundantes en lectores de pantalla (como VoiceOver o NVDA).

4.- UX y Layout

Consistencia: El componente asegura un espaciado constante --unav-spacing-md entre ítems.

Escalabilidad: Soporta inyección de iconos de múltiples librerías (Material Symbols, Bootstrap Icons) sin alterar la arquitectura base.

3. Iconos diferentes para características

unav-listIcon

Perfecto para presentar los atributos o metadatos de un Grado o Máster (fecha, lugar, modalidad, etc.).
