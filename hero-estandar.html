Design System UNAV

Componente Hero Estándar

Cabeceras inmensas (fullwidth) animadas con distribución modular de botones por cuadrantes.

Guía Técnica y Documentación Oficial

1. Implementación OOCSS y Estructura

  • Estructura Base: El Hero se construye sobre .unav-hero, requiriendo un contenedor interno .unav-heroContent para la jerarquía tipográfica y, opcionalmente, .unav-heroOverlay para garantizar el contraste sobre imágenes fotográficas.
  • Modificadores de Estilo: Soporta .unav-themeDark (para textos claros sobre fondos oscuros) y .unav-alignCenter para la alineación horizontal de todo el conjunto.

2. Guía Técnica (HTML/CSS)

  • Backgrounds Dinámicos: Se inyecta la imagen de fondo directamente en el estilo en línea del contenedor principal (background-image: url(...)), utilizando el formato WebP optimizado para alta resolución.
  • Tipografía: El título del Hero utiliza la escala var(--unav-fontSize300) con unav-lh-tight para un impacto visual máximo, mientras que el párrafo descriptivo usa var(--unav-fontSize125) y unav-lh-normal.

3. Accesibilidad (A11y) y Schemas (SEO)

  • Semántica SEO: El contenedor global debe marcarse como itemscope itemtype="https://schema.org/WebPageElement" o WPHeader (Semánticamente solo debe haber un único WPHeader por página). El título principal debe usar <h1> con itemprop="headline".
  • Contraste (WCAG): Es mandatorio el uso de una capa oscura (overlay) entre la imagen y el texto para superar los estándares de accesibilidad, especialmente sobre fotografías con zonas de brillo.

4. UX, Uso de Átomos y Medios

  • Integración de Átomos: El Hero alberga botones principales (.unav-botonPrimario) o secundarios con modificadores de ajuste (.unav-botonFit) para alineaciones específicas.
  • Formatos de Imagen: El Hero es el elemento que requiere mayor calidad. Se recomienda formato WebP con relación de aspecto 21:9 o 16:9 y una anchura mínima de 1920px para pantallas panorámicas, asegurando que el punto de interés de la imagen (focal point) no quede tapado por el texto.
