Listado de Noticias (8 Col)

Refinamiento del componente de lista con formato de fecha editorial y contención en grid central.

Mejoras Aplicadas

Formato Editorial

  • Fecha: Se implementa el formato solicitado "DD Mes. YYYY" (ej. 15 Abr. 2026).
  • Tipografía: Uso de pesos bold para la fecha para jerarquizar sobre el titular.

Contención Grid

  • Ancho de Bloque: El listado se confina en una columna de 8/12 (dentro del rango 6-9 solicitado).
  • Alineación: Centrado automático mediante utilidades de Bootstrap (justify-content-center).
