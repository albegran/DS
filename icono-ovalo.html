Design System UNAV

Iconografía

Librerías estándar y pautas para el uso e implementación de elementos iconográficos en el ecosistema digital.

Características Técnicas y Librería Propia

El sistema utiliza dos librerías externas mediante CDN (Bootstrap Icons y Google Material Symbols) para necesidades genéricas. Además, contempla la integración de una tercera librería de iconos propios.

Creación de Iconos Propios

  • Formato y Canvas: Diseñar en SVG puro sobre un artboard consistente (ej. 24x24px o 32x32px). Grosor recomendado de trazo: var(--unav-iconStrokeWeight).
  • Trazos: Expandir todos los trazos (outline strokes) para evitar distorsiones al redimensionar.
  • Color: No aplicar colores fijos. Usar la propiedad CSS fill="currentColor" en el SVG para heredar el color del contenedor (ej. comportamiento hover).

Integración y Escala

  • Escala Modular: Utilizar las clases utilitarias de tamaño .unav-icono-sm (16px), -md (20px), -lg (24px) o -xl (32px).
  • Implementación recomendada: SVG Sprites agrupados en un archivo HTML base inyectados mediante <svg><use href="#icon-name"></use></svg>, o mediante Webfonts generadas con IcoMoon.
