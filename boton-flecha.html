Design System UNAV

Enlace Flecha (CTA Terciario)

Componente de navegación ágil para enlaces de texto con animación de flecha integrada (efecto swipe).

Análisis Técnico y Documentación de Estilos

1. Implementación, Modificadores y Técnica

  • Implementación OOCSS: Invocar mediante la clase contenedora .unav-botonFlecha sobre una etiqueta de anclaje.
  • Modificadores de Instancia: La colorización es dinámica. Se inyecta la variable CSS --unav-arrowColor: var(--unav-color-*) directamente en el atributo style del elemento para alterar el color de todo el conjunto.
  • Construcción HTML/CSS/JS: Desarrollado en CSS puro (sin JS). Utiliza dos nodos <span> superpuestos (.unav-arrow y .unav-arrowClone) dentro de .unav-arrowWrapper para generar la ilusión óptica de deslizamiento continuo al hacer hover, aprovechando transiciones de transform.

2. Accesibilidad (A11y) y Schemas

  • Accesibilidad: Los elementos span internos que componen la flecha gráfica no contienen texto; por ello, los lectores de pantalla los ignoran. El enlace debe tener un texto descriptivo claro.
  • Schemas: Al ser un enlace de acción principal/secundaria, debe estar marcado con itemscope itemtype="https://schema.org/WebPageElement", definiendo su URL con itemprop="url" y su etiqueta con itemprop="name".

3. UX, Layout y Átomos en Componentes

  • UX y Layout: Al ser un elemento de tipo inline-flex, respeta el flujo de los textos (puede colocarse al final de un párrafo) o alinearse mediante las utilidades Flexbox de Bootstrap dentro de un Grid.
  • Uso de Átomos en Organismos: Este botón terciario es el átomo por defecto requerido al final de las "Tarjetas Modulares de Noticia" o dentro de "Acordeones" cuando se necesita redirigir a una página de profundidad.

4. Formato de Medios y Tipografía

  • Tipografía: El texto ancla consume el tamaño var(--unav-fontSize100) (16px) utilizando la fuente secundaria en mayúsculas var(--unav-fontFamilyPrimaryCondensed) con var(--unav-fontWeightBold), garantizando una lectura impactante.
  • Imágenes/Vídeos: Si este botón acompaña a un bloque multimedia (ej. Card de noticia), la imagen superior debe respetar un ratio estricto de 16:9 y suministrarse en formato WebP con un ancho máximo de 800px para la retícula de tarjetas.
