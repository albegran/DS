Design System UNAV

Enlace Bloque

Ítem de lista accionable con altura dinámica que abraza el texto. Conserva el color histórico mediante tokens locales e incluye microinteracción JS.

Análisis Funcional y Técnico

  • Integración en Grid: Pensado para ser utilizado en columnas medias (entre col-3 y col-6 de Bootstrap).
  • Tokenización Histórica: Se ha preservado el color corporativo como una variable de instancia (--unav-bloqueEnlaceBg) dentro del sistema.
  • Tipografía: Mapeado a --unav-fontSize100 y a la familia base corporativa (Roboto).
  • Renderizado DOM (JS): Utiliza getClientRects() para leer los fragmentos poligonales del texto renderizado y detectar con precisión milimétrica el ancho y posición de la última línea.
  • Subrayado Variable: Las coordenadas extraídas se inyectan en --unav-lineWidth, --unav-lineLeft y --unav-lineBottom, actuando sobre un pseudo-elemento ::after que se adapta a las roturas de línea.

Comportamiento fluido en Grid de Bootstrap

Interactúa (Hover) sobre cada bloque para observar cómo el motor JavaScript recalcula el subrayado basándose exactamente en dónde termina la última palabra, sin importar la anchura de la columna.
