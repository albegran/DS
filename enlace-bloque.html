Design System UNAV

Enlace Bloque

Ítem de lista accionable con altura dinámica que abraza el texto. Conserva el color histórico mediante tokens locales e incluye microinteracción JS.

Guía Técnica y Documentación Oficial

1. Implementación y Modificadores

  • Estructura OOCSS: Para enlaces independientes se invoca .unav-bloqueEnlace. Cuando se necesita una agrupación se envuelven en el contenedor .unav-listadoEnlaces para heredar la retícula y espaciado vertical.
  • Tokenización Histórica: El color base del bloque se gestiona como una variable local de instancia (--unav-bloqueEnlaceBg), respetando la identidad visual previa pero estandarizada.

2. Guía Técnica (HTML/CSS/JS)

  • Renderizado DOM (JS): El core funcional reside en el uso de getClientRects(). El JavaScript captura los fragmentos poligonales generados por los saltos de línea del texto para detectar el ancho y posición exactos de la última palabra renderizada.
  • CSS Dinámico: El JS inyecta variables nativas (--unav-lineWidth, --unav-lineLeft, --unav-lineBottom) al bloque para posicionar milimétricamente el pseudo-elemento ::after responsable del subrayado interactivo animado.

3. Accesibilidad (A11y) y Schemas

  • Accesibilidad: Alto ratio de contraste en hover asegurado. Todo bloque enlaza de forma descriptiva, y la animación del subrayado respeta el flujo sin causar saltos en el lector de pantalla.
  • Microdatos SEO: Al ser un menú lateral o un sumario de navegación profunda, debe envolverse en itemscope itemtype="https://schema.org/SiteNavigationElement" con enlaces marcados vía itemprop="url" y itemprop="name".

4. UX, Tipografía y Layouts

  • Integración en Grids: Diseñado expresamente para adaptarse y fragmentarse en columnas desde col-3 hasta col-6 en Bootstrap, asegurando el cálculo de la animación en cualquier viewport y adaptándose a layouts complejos.
  • Tipografía: El componente delega el texto a .unav-bloqueEnlaceText mapeando al token de lectura --unav-fontSize100 y a la familia de fuente Roboto, simulando el peso bold temporalmente en JS para pre-calcular el espacio en el efecto hover.
