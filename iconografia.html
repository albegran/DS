Iconografía

Librerías estándar y pautas para el uso e implementación de elementos iconográficos en el ecosistema digital.

Características Técnicas y Librería Propia

El sistema utiliza dos librerías externas mediante CDN (Bootstrap Icons y Google Material Symbols) para necesidades genéricas. Además, contempla la integración de una tercera librería de iconos propios.

Creación de Iconos Propios
  • Formato y Canvas: Diseñar en SVG puro sobre un artboard consistente (ej. 24x24px o 32x32px).
  • Trazos: Expandir todos los trazos (outline strokes) para evitar distorsiones al redimensionar.
  • Color: No aplicar colores fijos (`#hex`). Usar la propiedad CSS fill="currentColor" en el SVG para que herede el color de su clase contenedora (ej. hover en negro).
Integración en el CMS
  • Opción A (Recomendada): SVG Sprites. Se agrupan todos los SVGs en un único archivo oculto en el HTML base usando etiquetas <symbol id="icon-name">. Se inyectan con: <svg><use href="#icon-name"></use></svg>. Es lo mejor para rendimiento y accesibilidad.
  • Opción B: Webfont Custom. Empaquetar los SVGs usando herramientas como IcoMoon o Fontello. Te generarán los archivos WOFF2 y un CSS con clases tipo .unav-icon-mifigura.
