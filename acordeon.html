Acordeones y Desplegables

Componente flexible para la gestión de contenidos densos mediante visibilidad progresiva.

Guía Técnica y Documentación Oficial

1. Implementación OOCSS y Modificadores

  • Estructura Base: El organismo se envuelve en .unav-accordionGroup. Cada ítem consta de un botón .unav-accordionHeader y un contenedor .unav-accordionPanel.
  • Modificador de Comportamiento: Por defecto, los acordeones actúan como "mutuamente excluyentes" (cerrando el anterior). Si se añade la clase .unav-allowMulti al grupo contenedor, se permite la apertura simultánea de múltiples paneles.

2. Guía Técnica (HTML/CSS/JS)

  • Renderizado DOM (JS): Un script ligero y nativo interactúa con el DOM calculando dinámicamente el scrollHeight del panel al hacer clic, inyectándolo en la propiedad CSS max-height para sortear la limitación clásica de animación de height: auto.
  • CSS Motion: El movimiento y la rotación del icono indicador se gestionan vía CSS delegando la velocidad a los Motion Tokens del sistema, como var(--unav-durationNormal).

3. Accesibilidad (A11y) y Schemas (SEO)

  • A11y (Lectores de Pantalla): Es estricto el uso bidireccional de atributos. El botón requiere aria-expanded="true/false" y el panel oculto se gestiona visualmente a través del JS pero se oculta a la semántica si es necesario.
  • Microdatos de Google: Si el acordeón se usa para Preguntas Frecuentes, el contenedor global debe incluir itemscope itemtype="https://schema.org/FAQPage", marcando cada ítem como Question y el panel como Answer.

4. UX, Uso de Átomos y Layout

  • Integración de Átomos: El panel desplegable funciona como un lienzo libre que puede contener textos, "Botones Flecha" o listas en su interior.
  • Grids y Layouts: Los grupos de acordeón ocupan por defecto el 100% del contenedor padre. Se adaptan perfectamente a las columnas de Bootstrap, recomendándose anchos de lectura entre col-md-8 y col-md-10 centrados para evitar líneas de texto excesivamente largas.

Si se añade la clase .unav-allowMulti al contenedor principal, los paneles no se colapsan automáticamente al abrir uno nuevo.
