Efecto Subrayado al Scroll

Componente de marcado completo (100% altura) con variantes para temas claro y oscuro.

Análisis Funcional y Técnico

El componente detecta el viewport para desplegar un fondo dinámico que resalta conceptos. Ahora ajustado para cubrir toda la caja del texto (100% height) y preparado para fondos oscuros.

Análisis Funcional

  • Modo Claro: Utiliza el token --unav-yellow-300. Ideal para artículos o noticias estándar.
  • Modo Oscuro: Utiliza el token --unav-grey-600 mediante la clase .unav-resaltadorInverso para garantizar accesibilidad sobre texto blanco.

Especificaciones Técnicas

  • Estructura CSS: Se modifica el gradiente base a transparent 0% para abarcar el total de la altura de línea de la tipografía.
  • Nomenclatura y JS: API IntersectionObserver estructurada usando camelCase, inyectando la clase activa sin causar reflujos continuos en el DOM.

Variante 1: Fondo Claro (Por defecto)

Las expediciones a las cimas más altas del planeta requieren una preparación técnica excepcional. Cuando los alpinistas superan la altitud crítica, el oxígeno escasea drásticamente. Es en este preciso instante cuando entrar en la llamada zona de la muerte se convierte en el mayor desafío para el ser humano. El tiempo corre en contra y las decisiones deben tomarse con rapidez.

Variante 2: Fondo Oscuro (Negativo)

La aclimatación progresiva es fundamental en cualquier escalada de nivel 8.000. Los campamentos intermedios no solo sirven para el descanso físico, sino para asegurar que el cuerpo se acostumbra a la baja presión atmosférica, un factor que marca la diferencia entre el éxito y el fracaso absoluto en la ascensión final. Ignorar este paso es letal.
