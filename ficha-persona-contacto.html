Fichas de Persona y Contacto

Componentes modulares para representar perfiles humanos o datos de contacto de forma estructurada.

Guía Técnica y Documentación Oficial

1. Implementación OOCSS y Modificadores

  • Estructura Base: El componente maestro se construye sobre .unav-card.unav-cardSolid. Internamente se orquesta mediante los bloques .unav-avatar para la imagen de perfil y .unav-contactoBox para las tarjetas internas de información.
  • Modificadores de Avatar: La clase .unav-avatarImg asegura que la fotografía se adapte perfectamente al círculo geométrico, recortando los excesos proporcionalmente (object-fit).

2. Guía Técnica (HTML/CSS)

  • Renderizado CSS: Las tarjetas de contacto utilizan utilidades nativas de Flexbox para alinear iconos descriptivos con la información textual en perfecta simetría vertical.
  • Interactividad Funcional: Los enlaces a teléfonos y correos electrónicos exigen el uso estricto de los protocolos nativos tel: y mailto: en el atributo href para disparar la acción en dispositivos móviles de forma automática.

3. Accesibilidad (A11y)

  • Accesibilidad: Las imágenes de avatar deben llevar atributo alt explícito con el nombre de la persona para facilitar la labor de los lectores de pantalla.

4. UX, Integración de Átomos y Layouts

  • Componentes Anidados: Este organismo es un "contenedor de átomos". Consume internamente Etiquetas (.unav-tag) para mostrar el departamento, e incorpora los Enlaces Flecha (.unav-enlaceFlecha) o botones secundarios como Call To Action (CTA).
  • Layouts y Medios: Adaptación líquida en el Grid de Bootstrap. Las imágenes de perfil (Avatares) deben suministrarse con relación de aspecto 1:1, formato WebP y peso ligero, recomendándose una resolución óptima de 400x400px.
