Fichas de Persona y Contacto

Componentes modulares para representar perfiles humanos o datos de contacto de forma estructurada.

Análisis Funcional y Técnico

El componente de Ficha de Persona y Contacto (.unav-personCard) es una solución modular diseñada bajo la metodología OOCSS para estructurar e identificar información de personas, cargos institucionales y departamentos. Utiliza la flexibilidad de Flexbox para alterar dinámicamente el orden visual de sus campos sin alterar la semántica del HTML ni degradar el SEO o la accesibilidad.

Análisis Funcional

  • Campos específicos: Soporta fotografía cuadrada (relación de aspecto 1:1), nombre, puesto de trabajo, dirección completa, teléfonos múltiples y botones secundarios de acción.
  • Variabilidad de layouts: Permite ordenar de forma completamente asíncrona la posición de los campos mediante las clases de variante.

Especificaciones Técnicas

  • Propiedad Order: El reordenamiento de los campos se logra controlando de forma atómica la propiedad order de CSS en las clases modificadoras (.unav-layoutPersona, .unav-layoutContacto, .unav-layoutDirectivo, .unav-layoutPerfilContacto).
  • Esquinas y Proporciones: La fotografía se fuerza mediante CSS con aspect-ratio: 1 / 1 y object-fit: cover para garantizar el formato cuadrado sin distorsión.
