Separador (Divider)

Línea divisoria responsiva. Permite anchos porcentuales, márgenes, alineaciones horizontales, estilos de línea (solid, dotted), iconos y textos incrustados.

Resumen Técnico y Funcional

Este componente actúa como una línea divisoria (divider) altamente modular controlada mediante variables CSS. Está diseñado con Flexbox, permitiendo incrustar de forma natural textos o iconos, equilibrando los márgenes automáticamente a cada lado de forma responsiva para cualquier grid de Bootstrap.

  • Clase Principal: .unav-separador
  • Alineación: .unav-separadorAlignLeft, Center, Right
  • Variables Claves: --unav-sepWidth, --unav-sepColor, --unav-sepStyle
  • Contenido Interno: Soporta .unav-separadorText e Icon en .unav-separadorContent
  • Estilos de línea: Admite solid o dotted.
  • SEO / Accesibilidad: Marcado WebPageElement de schema.org integrado.

Con Iconos y Texto (Roboto Condensed)

Añadiendo el contenedor .unav-separadorContent entre las líneas. Se controla a través de variables CSS para el ancho, el estilo (solid/dotted) y la alineación.
