Separador (Divider)

Línea divisoria responsiva OOCSS. Permite anchos porcentuales, márgenes, alineaciones horizontales, estilos de línea e incrustación de contenido.

Análisis Funcional y Técnico

Este componente actúa como una línea divisoria (divider) altamente modular. Está diseñado con Flexbox, permitiendo incrustar de forma natural textos o iconos, equilibrando los márgenes automáticamente a cada lado de forma responsiva para cualquier grid de Bootstrap. Toda su apariencia se delega en Design Tokens y CSS Variables locales.

  • Clase Principal: .unav-separador
  • Alineación: .unav-separadorAlignLeft, Center, Right
  • Variables de Instancia: --unav-separadorWidth, --unav-separadorColor, --unav-separadorStyle
  • Contenido Interno: Soporta .unav-separadorText e Icon dentro de .unav-separadorContent. Consume tipografía corporativa.
  • Estilos de línea: Admite solid, dotted, dashed.
  • SEO: Marcado WebPageElement de Schema.org integrado por defecto.

Catálogo de Variantes con Tokens Inyectados

El contenedor .unav-separadorContent equilibra el espacio. El color se inyecta reasignando --unav-separadorColor a cualquier color base de nuestra paleta.
