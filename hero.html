Componente Hero

Visualización de 5 variantes de banners inmensos. Cada ejemplo utiliza una disposición específica, combinando imágenes responsivas de fondo y la inyección del componente botón estandarizado.

Resumen Técnico y Funcional

Este componente sirve como cabecera principal de impacto (Hero) para aperturas de página. Demuestra cómo el layout desacopla las capas visuales mediante posicionamiento absoluto y Flexbox. En escritorio, los botones se sitúan por cuadrantes; en móvil, colapsan en una pila inferior para mejorar el alcance del pulgar (Thumb Zone), asegurando legibilidad general a través de capas de oscurecimiento (overlays) para los textos centrados.

Layout contenedor: Elementos posicionales .unav-heroVisuals con Flexbox.

Tipografía: Jerarquía <h1> en Roboto Thin 80px.

Imágenes: Intercambio CSS display:none para imágenes móviles/escritorio (aspect-ratio 4/5 y 21/9).

Integración DS: Inyección directa del componente .unav-botonPrimario.

Responsive: Media queries en el break-point de 768px.

SEO/GEO: Etiquetado WPHeader y propiedades itemprop="headline" de Schema.org.
