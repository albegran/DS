Bloque de Enlace (Navigational Block)

Ítem de lista accionable con altura dinámica que abraza el texto. Conserva el color histórico mediante tokens locales e incluye microinteracción JS.

Resumen Técnico y Funcional

  • Naturaleza de Bloque: Semánticamente es un <a> configurado como display: block (Actionable List Item).
  • Tokenización Histórica: Se ha preservado el color `#e3eaed` como una variable de instancia (--unav-bloqueEnlaceBg) dentro de unav-variables.css, manteniendo limpia la paleta primitiva.
  • Tipografía: Mapeado a --unav-fontSize100 y a la familia base corporativa (Roboto)[cite: 11].
  • Renderizado DOM (JS): Utiliza getClientRects() para leer los fragmentos poligonales del texto renderizado y detectar con precisión milimétrica el ancho y posición de la última línea[cite: 11].
  • Subrayado Variable: Las coordenadas extraídas se inyectan en --unav-lineWidth, --unav-lineLeft y --unav-lineBottom, actuando sobre un pseudo-elemento ::after[cite: 11].
