Listado de Enlaces

Bloque estructural para la organización de navegación vertical con subrayado dinámico de precisión.

Resumen Técnico y Funcional

Este bloque estructural define cómo se agrupan los átomos .unav-listItem. La clave del diseño es el margen inferior de 2px, que crea una separación sutil pero clara. Se integra limpiamente en el grid de Bootstrap para generar bloques de enlaces en columnas sin necesidad de contenedores adicionales ni títulos. Incorpora el subrayado inteligente por JavaScript que abraza exclusivamente la última línea del texto.

  • Jerarquía: Molécula compuesta por átomos .unav-listItem adaptativos.
  • Layout: Se apilan verticalmente dentro de columnas con altura dinámica.
  • SEO: Implementa ItemList para indexación de menús.
  • Naming: Uso de camelCase para clases internas y variables JS.
  • Accesibilidad: Hitbox completo del bloque para facilitar el clic.
