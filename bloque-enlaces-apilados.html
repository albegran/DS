Listado de Enlaces

Bloque estructural para la organización de navegación vertical.

Resumen Técnico y Funcional

Este bloque estructural define cómo se agrupan los átomos .unav-listItem. La clave del diseño es el margen inferior de 2px, que crea una separación sutil pero clara. Se integra limpiamente en el grid de Bootstrap para generar bloques de enlaces en columnas sin necesidad de contenedores adicionales ni títulos.

  • Jerarquía: Molécula compuesta por átomos .unav-listItem.
  • Layout: Se apilan verticalmente dentro de columnas.
  • SEO: Implementa ItemList para indexación de menús.
  • Naming: Uso de camelCase para clases internas.
  • Accesibilidad: Hitbox completo del bloque para facilitar el clic.
