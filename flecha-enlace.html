Enlace Flecha

Componente interactivo con animación infinita y validación de accesibilidad integrada.

Resumen Técnico y Funcional

Este componente visual está diseñado para actuar como un enlace de acción (Call-to-Action) con una microinteracción dinámica de bucle infinito en hover. Su propósito principal es guiar la navegación del usuario de forma intuitiva, destacando enlaces a contenidos extendidos o páginas de detalle. Técnicamente, utiliza animaciones CSS optimizadas para el rendimiento y variables personalizadas para una integración fluida con la identidad corporativa.

  • Clase Principal: .unav-link
  • Tipografía: Roboto Black / Roboto (18px, 400w)
  • Dependencias: Requiere color.css para las variables de color.
  • Responsivo: Adaptado para grid de 2 columnas (escritorio).
  • Interacción: Animación lineal infinita en estado :hover.
  • SEO: Soporta marcado Schema.org WebPageElement.
  • Accesibilidad: Requiere ratio > 4.5:1 para cumplimiento AA.
