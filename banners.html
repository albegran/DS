Design System UNAV

Sistema de Banners

Arquitectura unificada para bloques promocionales con colorización dinámica de CTAs e interlineado normativo.

Guía Técnica y Documentación Oficial

1. Implementación y Modificadores

  • Clases OOCSS: Base .unav-banner. Modificadores de tamaño: .unav-bannerFull (100vw), .unav-bannerWide (ancho de contenedor) y .unav-bannerMini (cajas compactas).
  • Modificadores de Estilo: .unav-themeDark invierte los textos a blanco. .unav-efectoParallax activa el background-attachment: fixed. .unav-alignCenter centra el contenido interno.

2. Guía Técnica (HTML/CSS) y Colorización

  • Estructura: Requiere un .unav-bannerOverlay para oscurecer/matizar el fondo y un .unav-bannerContent que actúa como capa superior (z-index) para el texto.
  • Botones Dinámicos: Se inyecta --unav-botonColorSource: #ffffff; en los botones para destacarlos, utilizando tonos vibrantes (Cyan 400, Yellow 400) para llamadas a la acción sobre fondos dominantes.

3. Accesibilidad (A11y) y Schemas

  • Contraste Seguro: El uso de .unav-bannerOverlay es obligatorio sobre imágenes fotográficas para garantizar el contraste AAA exigido por las normativas WCAG.
  • Microdatos: Todo banner promocional debe marcarse semánticamente como itemscope itemtype="https://schema.org/WPAdBlock", identificando el título y la descripción para motores de búsqueda.

4. Layout, Tipografía y Medios

  • Control Tipográfico: Los títulos exigen .unav-lh-snug y los párrafos .unav-lh-normal para un interlineado correcto.
  • Imágenes WebP: Se requiere formato WebP optimizado. Las resoluciones varían: 1920px (Full), 1200px (Wide) y 800px (Mini). La inyección se hace inline en CSS (background-image).
