Design System UNAV

Textos Títulos Destacados

Frases de alto impacto visual sin peso jerárquico ni indexación estructural para motores de búsqueda.

Análisis y Documentación Oficial

1.- Guía de Implementación y Modificadores

Uso de clases: Todo texto destacado debe incluir la clase base .unav-titulo (para asegurar el reset de márgenes y comportamiento de bloque). A esto se suman las clases atómicas de formato (.unav-font-*, .unav-weight-*, .unav-text-*, .unav-lh-*).

Modificadores: No requiere variantes preconfiguradas, ya que su propia naturaleza es la composición visual libre mediante utilidades atómicas.

2.- Guía Técnica

Construcción: Emplear etiquetas HTML neutras como <p>, <div> o <span>. La inyección cromática se aplica directamente con variables CSS en línea (color: var(--unav-...);).

JS y Animación: Opcionalmente, se pueden integrar con el sistema de movimiento vinculando las clases .unav-efectoEntradaOculto que serán gestionadas por el IntersectionObserver genérico del sistema.

3.- Accesibilidad (A11y) y Schema.org

Impacto SEO Neutro: A diferencia de las cabeceras (H1-H6), estos elementos son leídos como "texto de contenido común" por las herramientas asistivas. Esto permite crear enormes Claims publicitarios sin secuestrar la jerarquía del documento. No utilices role="heading".

Schema.org: Si estos claims refuerzan un producto o valor corporativo, pueden marcarse con itemprop="abstract" o simplemente evitar marcados semánticos si son puramente estéticos.

4.- UX, Layout y Medios

Propósito Visual: Utiliza estos elementos para citas destacadas (Blockquotes de diseño), introducciones largas (Leads) o mensajes de marketing agresivos que requieren fuentes Display o tipografías masivas como .unav-text-500.

Respiración: Al usar tamaños de texto muy altos, es imperativo usar .unav-lh-tight (1.1) para que los bloques mantengan cohesión en pantallas móviles (menor viewport width).
