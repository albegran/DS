Lista Descriptiva

Componente para presentar términos y descripciones de forma estructurada, con iconos, integración cromática e inyección de tokens.

Resumen Técnico y Funcional

Este componente utiliza etiquetas semánticas HTML5 (<dl>, <dt>, <dd>) integradas con marcado de schema.org para favorecer el SEO semántico. Es altamente adaptable y consume estrictamente la arquitectura de Design Tokens para colores, espacios y tipografías[cite: 12].

  • Estructura base: Bloques .unav-descList, .unav-descItem y variante .unav-descItemHanging[cite: 12].
  • Elementos internos: Clases OOCSS .unav-descTerm, .unav-descDefinition, .unav-descIcon[cite: 12].
  • Modificadores de Estilo: Uso de la clase utilitaria .unav-hasBorder[cite: 12].
  • Colorización por Tokens: Las variantes de color se logran inyectando la variable de instancia --unav-descColorPrimary y --unav-descBorderColor mapeadas al archivo color.css corporativo[cite: 12].
  • Grid: Completamente responsivo, apto para columnas Bootstrap (flexbox)[cite: 12].
  • SEO: Implementación de Schema.org DefinedTermSet y DefinedTerm[cite: 12].
