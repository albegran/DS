Lista Descriptiva

Componente para presentar términos y descripciones de forma estructurada, con iconos e integración cromática corporativa.

Resumen Técnico y Funcional

Este componente utiliza etiquetas semánticas HTML5 (<dl>, <dt>, <dd>) integradas con marcado de schema.org para favorecer el SEO semántico. Es altamente adaptable, apilable y permite personalización de color.

  • Estructura base: .unav-descList, .unav-descItem, .unav-descItemHanging
  • Elementos internos: .unav-descTerm, .unav-descDefinition, .unav-descIcon
  • Modificadores: .unav-hasBorder y clases de color.
  • Colores Soportados: Integra variables de color.css (Rojo, Azul, Teal, etc.).
  • Grid: Completamente responsivo, apto para columnas Bootstrap.
  • SEO: Schema.org DefinedTermSet y DefinedTerm.
