Etiquetas (Tags)

Componente atómico informativo. Utilizado para categorizar contenido visualmente sin generar interacción de enlace.

Resumen Técnico y Funcional

Las etiquetas son meramente informativas. Se ha ajustado la fuente original (8px) a 12px y peso 500 (Medium) para cumplir con los estándares de accesibilidad web (WCAG), manteniendo el aspecto compacto mediante el uso proporcional de padding. La nomenclatura respeta camelCase.

  • Clase Base: .unav-tag
  • Modificadores de Color: Ej. .unav-tagRojo, .unav-tagBlueDark
  • Tipografía: Roboto 12px (Medium 500)
  • Contraste: Fondo nivel 100 + Texto nivel 800
  • Comportamiento: inline-flex (No clickeables, user-select: none)
  • Marcado: Schema.org keywords al agruparlas.
