Design System UNAV

Etiquetas (Tags)

Componente atómico informativo. Utilizado para categorizar contenido visualmente sin generar interacción de enlace.

Análisis Funcional y Técnico

Las etiquetas son meramente informativas. Se consumen estrictamente el token --unav-fontSize075 (12px) y el peso --unav-fontWeightMedium de nuestro sistema tipográfico[cite: 6] para cumplir con los estándares de accesibilidad web (WCAG), manteniendo el aspecto compacto.

  • Clase Base: Abstracción OOCSS mediante .unav-tag.
  • Modificadores de Color: Aplicando sufijo camelCase (ej. .unav-tagRojo).
  • Tipografía: Familia principal (Roboto)[cite: 6].
  • Contraste Accesible: Combinación automatizada del fondo nivel 100 con texto nivel 800[cite: 4].
  • Comportamiento: inline-flex (No clickeables, deshabilitada la selección de texto).
  • Marcado: Schema.org keywords al agruparlas.
