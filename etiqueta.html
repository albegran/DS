Etiquetas (Tags)

Componente atómico informativo. Utilizado para categorizar contenido visualmente sin generar interacción de enlace.

Guía Técnica y Documentación Oficial

1. Guía de Implementación y Modificadores

  • Estructura OOCSS: Todo bloque requiere la clase atómica base .unav-tag para la geometría y el reset de márgenes.
  • Modificadores Cromáticos: Posee más de 20 pieles de color añadiendo el sufijo CamelCase de la familia cromática (ej. .unav-tagBlueDark, .unav-tagRojo).

2. Guía Técnica (HTML/CSS/JS) y Fuentes

  • Construcción: Nodos <span> renderizados con display inline-flex en CSS puro, sin dependencias de JavaScript.
  • Tipografía: El sistema inyecta el token de lectura compacta var(--unav-fontSize075) (12px) mediante la fuente principal var(--unav-fontFamilyPrimary) y el grosor var(--unav-fontWeightMedium).

3. Accesibilidad (A11y) y Schemas

  • Accesibilidad y Contraste WCAG: Al ser puramente informativas, deshabilitan la selección (user-select: none). Su algoritmo CSS mezcla automáticamente fondos muy suaves (nivel 100) con textos muy oscuros (nivel 800) para garantizar el AAA.
  • Microdatos SEO: Se deben agrupar en un contenedor semántico que integre la propiedad itemprop="keywords".

4. UX, Layouts y Átomos / Medios

  • UX y Componentes: Actúan como un "átomo" de metadatos insertado dentro de componentes más complejos, como cabeceras de noticia o Tarjetas Modulares (Articles).
  • Medios y Layouts: Típicamente agrupados con d-flex flex-wrap gap-2. Cuando acompañan a medios visuales en tarjetas, las imágenes y vídeos deben seguir el formato WebP con relación de aspecto 16:9 y un peso no superior a 800px de ancho.
