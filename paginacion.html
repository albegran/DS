Design System UNAV

Paginación (Pagination)

Control de navegación secuencial desacoplado basado en la arquitectura atómica de botones.

Guía Técnica y Documentación Oficial

1. Implementación OOCSS y Estructura

  • Estructura Base: El componente se enmarca en un elemento <nav> con clase .unav-paginacionContainer. Los ítems se organizan en una lista desordenada <ul> con elementos <li>.
  • Modificadores: La clase .unav-paginacionItem estandariza el tamaño táctil. El estado activo o actual se señala mediante .unav-isActive, que aplica una variante de estilo específica mediante el sistema OOCSS.

2. Guía Técnica (HTML/CSS)

  • Geometría: Basado en el sistema de botones del DS, reutiliza los tokens de padding y border-radius para garantizar que cada número sea un área de clic óptima (mínimo 44px de zona táctil).
  • Iconografía: Utiliza el átomo .material-symbols-outlined para los indicadores de flecha, garantizando una escala vectorial perfecta y escalable sin degradación.

3. Accesibilidad (A11y) y Schemas (SEO)

  • Accesibilidad (A11y): Obligatorio el uso de aria-label descriptivos en los botones de "Página siguiente/anterior" para que los lectores de pantalla expliquen la navegación correctamente. La página actual debe incluir aria-current="page".
  • Schemas: Es recomendable envolver el contenedor en un schema de navegación https://schema.org/SiteNavigationElement.

4. UX, Integración y Layouts

  • UX de Navegación: La paginación siempre debe ser predecible. Se recomienda centrar el componente mediante justify-content-center en el contenedor <ul> para mejorar la visibilidad dentro de la página.
  • Layouts: Este átomo es extremadamente ligero y se inserta al pie de cualquier grid de datos (noticias, eventos, tablas). No tiene dependencias de ancho fijo, adaptándose al flujo de la columna donde se sitúe.
