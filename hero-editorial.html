Efecto Text Reveal (Hero Editorial)

Patrón de animación pura por CSS para grandes reportajes, asegurando visibilidad inmediata en el primer renderizado (Above the Fold).

Análisis Funcional y Técnico

Este componente crea la ilusión de que el titular emerge desde líneas base invisibles. Se ha optimizado para prescindir de JS en el bloque principal, garantizando que el texto nunca quede oculto por fallos en los observadores del DOM.

SEO y Semántica

  • Schema.org: Se utiliza itemscope itemtype="https://schema.org/Article" envolviendo todo el componente.
  • Estructura HTML: El contenedor del título sigue siendo un único <h1> para mantener el valor de jerarquía para los motores de búsqueda.

Especificaciones Técnicas

  • Keyframes CSS: El efecto se lanza nativamente con la propiedad animation y animation-delay en línea para escalonar la aparición.
  • Fallback visual: Si la animación falla por configuración del dispositivo, el estado forwards fuerza a mostrar el contenido final.
