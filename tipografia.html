3. Escala de Interlineado (Line Height)

El interlineado debe ajustarse según el tamaño del texto. Textos grandes requieren interlineados estrechos (Tight), mientras que párrafos pequeños requieren interlineados más amplios (Relaxed) para mejorar la lectura.

.unav-lh-tight (1.1)

Titulares Gigantes
Necesitan Espacio
Muy Reducido

.unav-lh-normal (1.5)

Este es el interlineado base estándar del sistema. Se utiliza para la lectura de párrafos convencionales. Permite que el ojo humano transite de una línea a otra sin esfuerzo, evitando la fatiga visual en textos de media y larga extensión.

.unav-lh-snug (1.25)

Interlineado intermedio ideal para subtítulos o sumarios de noticia.

.unav-lh-relaxed (1.75)

Cuando el texto es extremadamente pequeño (075), aumentamos ligeramente el interlineado para evitar que las líneas colisionen. Este comportamiento es vital en notas legales, referencias al pie o textos meta que ocupan varias líneas.

4. Enlaces Inline (Cuerpo de texto)

Los enlaces que conviven dentro de párrafos estándar (Roboto, Regular 400, 1.125rem) deben utilizar la clase .unav-enlaceInline. Esta abstracción aplica el color corporativo institucional y un subrayado desplazado (offset) que mejora significativamente la legibilidad y la accesibilidad (WCAG) sin recargar la lectura. Para fondos oscuros o corporativos, se utiliza el modificador .unav-enlaceInlineBlanco.

.unav-enlaceInline
