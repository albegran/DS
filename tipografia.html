Design System UNAV

Sistema Tipográfico

Consumo de clases utilitarias (Tokens) para fragmentos de Liferay 7.4 y aplicaciones web.

Análisis Funcional y Técnico

El sistema tipográfico de la Universidad de Navarra se fundamenta en proporciones matemáticas para garantizar consistencia visual, jerarquía clara y máxima legibilidad en múltiples dispositivos.

Análisis Funcional

  • Familias Principales: Roboto y Roboto Condensed conforman la base de la interfaz de usuario.
  • Familias Secundarias: Playfair Display, Roboto Slab y DM Serif Text reservadas para entornos editoriales, citas o títulos de gran impacto.
  • Escala Modular: Variaciones de tamaño estrictamente definidas para evitar la arbitrariedad en la construcción de componentes.

Especificaciones Técnicas

  • Clases OOCSS: Uso intensivo de utilidades atómicas (ej. .unav-font-primary, .unav-weight-bold, .unav-text-200) para modificar estilos HTML directamente sin engordar los archivos CSS locales.
  • Variables CSS Raíz: Tamaños declarados en rem relativos a la escala root, garantizando adaptabilidad nativa de accesibilidad.
