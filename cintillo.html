Design System UNAV

Cintillo Titulaciones

Cinta modular de metadatos rápidos para mostrar características clave de Grados, Másteres y Doctorados.

Análisis y Documentación Oficial

1.- Guía de Implementación y Estructura

Componente Molecular: Basado en el contenedor .unav-cintillo, envuelve una lista semántica .unav-cintilloList. Cada bloque de información es un .unav-cintilloItem.

Composición: Los ítems están formados por el átomo icónico (.unav-cintilloIcon) y clases utilitarias tipográficas para el texto descriptivo, lo que permite escalabilidad sin necesidad de escribir CSS adicional.

2.- Guía Técnica (CSS / Flexbox)

Físicas de Centrado: El cintillo está construido sobre un motor Flexbox estricto. La propiedad justify-content: center garantiza el equilibrio en pantallas panorámicas, y align-items: stretch obliga a todos los ítems a tener la misma altura visual.

Variables (Tokens): Se nutre del token var(--unav-grey-100) para el fondo de base y var(--unav-spacing-md) / var(--unav-spacing-lg) para las distancias internas, preservando el ritmo vertical corporativo.

3.- Accesibilidad (A11y) y Semántica

Puntos de Referencia: El envoltorio global debe ser una etiqueta <section> acompañada de un atributo aria-label="Características de la titulación" para que los lectores de pantalla comprendan el contexto de los datos.

Iconos Decorativos: Los iconos de Google Fonts no son texto real. Deben llevar siempre el atributo aria-hidden="true" para no generar ruido (lecturas confusas) a usuarios invidentes.

4.- UX, Layout y Comportamiento Mobile

Evitar Salto de Líneas (No-Wrap): A nivel de UX móvil, apilar 8 características generaría una lista inmensa que empujaría el contenido relevante hacia abajo.

Scroll Inercial Inteligente: Se fuerza un carril infinito horizontal usando overflow-x: auto. Además, se añade una pequeña media-query para que en móviles el centrado se libere y el usuario pueda hacer scroll horizontal libremente sin que la física del centrado le oculte las opciones de la izquierda.
