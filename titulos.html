Design System UNAV

Títulos (Semántica Desacoplada)

Muestrario de contenedores neutros (p, div, span) transformados visualmente en titulares de alto impacto.

Análisis Funcional y Técnico

A diferencia del componente de Cabeceras (H1-H6), este componente demuestra el poder de los Design Tokens inyectados en elementos no jerárquicos usando la clase base .unav-titulo. Ideal para hero banners o pull quotes que requieren un peso visual enorme sin alterar la jerarquía SEO estricta del documento.

  • Generación: Motor JS iterativo que genera las permutaciones estáticas para todas las fuentes.
  • Interlineado Inteligente: Asignación del token --unav-lineHeight correcto (Tight, Snug o Normal) en función del tamaño del texto de la misma manera que las cabeceras.
  • Clase Maestra: Todos los elementos aplican class="unav-titulo" para resetear márgenes y comportarse como bloque.
  • Accesibilidad (ARIA): Todos los ejemplos inyectan role="heading" y aria-level="2" para que los lectores de pantalla los reconozcan correctamente como títulos de sección.
