Botón Secundario

Componente versátil para acciones complementarias y controles de interfaz.

Análisis Funcional y Técnico

Análisis Funcional

  • Propósito: Acciones alternativas o pasos secundarios.
  • Nueva Variante: Botones de "solo icono" para controles de navegación (galerías, paginadores).

Especificaciones Técnicas

  • OOCSS: Clase utilitaria .unav-botonIconOnly para forzar proporciones 1:1.
  • Colorización: Consumo del token dinámico --unav-botonColorSource.
