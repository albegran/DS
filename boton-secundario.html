Botón Secundario

Componente versátil para acciones complementarias y controles de interfaz.

Guía Técnica y Documentación Oficial

1.- Guía de Implementación y Modificadores

Clases OOCSS: Aplicar .unav-boton junto con la piel .unav-botonSecundario (transparente) o .unav-botonSecundarioInverso (fondo sólido).

Modificadores de Control: Usa .unav-botonIconOnly para forzar proporciones 1:1. Combínalo con .unav-botonIconOnlySm para controles de galería miniatura (32px).

2.- Guía Técnica (HTML, CSS y JS)

Colorización: Inyección dinámica a través de la variable de instancia CSS --unav-botonColorSource. El sistema OOCSS se encarga de calcular fondos y bordes en estado hover automáticamente.

Tipografía: Renderiza en var(--unav-fontSize08125) (13px) con la familia Condensed para optimizar espacio en barras de herramientas.

3.- Accesibilidad (A11y)

Soporte para Lectores de Pantalla: Todo botón que use la variante .unav-botonIconOnly carece de texto visible. Es estricto añadir aria-label="Acción" al botón y aria-hidden="true" al icono.

4.- UX y Uso de Átomos

Comportamiento en Layouts: Estos botones consumen width: fit-content por defecto, amoldándose naturalmente a columnas de Grid o contenedores Flexbox.

Componentes Complejos: Actúa como el átomo de control principal en organismos como galerías de vídeo (Sm) y botoneras de compartir en redes sociales.
