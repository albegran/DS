Design System UNAV

Movimiento e Interacción

1. Feedback por Opacidad (Hover)

INTERACCIÓN CSS

Clases para proporcionar feedback visual inmediato al usuario sin transformar el tamaño de los elementos.

.unav-efectoOpacidadSutil (85%)
.unav-efectoOpacidadIntensa (70%)

2. Elevación Z-Index (Lift)

INTERACCIÓN CSS

Levanta el elemento en el eje Y y expande su sombra proyectada. Estándar para tarjetas clickeables.

.unav-efectoElevacion
.unav-efectoElevacion

3. Microinteracción de Imagen (Zoom)

INTERACCIÓN CSS

Escala la imagen interna sin desbordar su contenedor original. Base para tarjetas de noticias o perfiles.

4. Aparición Básica (Fade In)

ANIMACIÓN JS/CSS

Animación de entrada (keyframes) que transiciona la opacidad de 0 a 1.

.unav-efectoFadeIn

5. Entrada en Cascada (Staggered Fade-Up)

INTERSECTION OBSERVER

Utilizado por defecto al hacer scroll. Elementos en estado .unav-efectoEntradaOculto reciben la clase .unav-efectoEntradaVisible con retraso secuencial.

6. Transición Cross-Fade (Pixelflakes)

ESTADOS JS/CSS

El elemento entrante .unav-isActive se escala a 1 y opacidad 1. El saliente .unav-isOutgoing se desvanece pero mantiene su escala para un cruce suave.

7. Desvanecimiento Interfaz Multimedia

ESTADOS JS/CSS

Utilizado en el Hero Vídeo. Los textos portan .unav-efectoDesvanecerTextos. Al inyectar .unav-isHidden, transicionan opacidad y visibilidad, desapareciendo del flujo de clics.

Titular de Vídeo

Este texto desaparece para no estorbar el vídeo.

8. Parallax (Fondo Fijo)

CSS NATIVO

Requiere hacer scroll en la página para ver el efecto. Se desactiva automáticamente en móviles por rendimiento.

.unav-efectoParallax

9. Ken Burns (Zoom Infinito)

KEYFRAMES (20s)

Animación lenta, continua y de ida y vuelta para dotar de vida a imágenes de fondo en banners largos.
