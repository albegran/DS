Design System UNAV

Tablas de Datos

Estructuras semánticas para datos tabulares con comportamiento responsivo OOCSS.

Análisis Funcional y Técnico

Estructura OOCSS

  • Marcado Nativo: Utiliza exclusivamente <table>, <thead>, <th> y <td> para garantizar la máxima accesibilidad para lectores de pantalla.
  • Filas de Agrupación: Uso de <tr class="unav-tableGroupHeader"> con un atributo colspan para segmentar datos (ej. semestres) de forma elegante y reducir el ruido visual.

Control Responsivo

  • Modo Stack (Apilado): Añadiendo .unav-tableResponsiveStack, las filas se convierten en "Tarjetas" en móvil. El atributo data-label="X" inyecta el nombre de la cabecera en cada celda.
  • Interactividad Inline: Integración natural de la clase .unav-enlaceInline para enlaces dentro de las celdas (ej. Guías Docentes).
