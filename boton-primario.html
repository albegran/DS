Design System UNAV

Botón Primario

Componente base abstracto implementando la arquitectura OOCSS (separación de estructura y piel).

Análisis Funcional y Técnico

El botón primario es el elemento clave de llamada a la acción (CTA). Su diseño modular permite adaptarse a diferentes contextos visuales mediante el consumo de los tokens del sistema.

Análisis Funcional

  • Propósito: Destacar la acción más importante de una vista (ej. "Enviar", "Guardar"). Evitar múltiples botones primarios con el mismo peso en pantalla.
  • Iconografía: Admite la integración de íconos provenientes de cualquiera de las tres fuentes definidas (Bootstrap Icons, Material Symbols o SVG propios de UNAV) para reforzar el significado de la acción.
  • Estados de Interacción: Posee estilos claramente diferenciados para los estados por defecto, hover (con variantes de borde interior) y desactivado (disabled).

Especificaciones Técnicas

  • OOCSS (Clase Base): La clase .unav-boton abstrae el layout (flexbox, gap, padding). La clase .unav-botonPrimario es únicamente la "piel" (colores).
  • Variables CSS (camelCase): Su colorización funciona reasignando variables locales (--unav-botonBg, --unav-botonBorder) que apuntan directamente a los tokens de unav-color.css.
  • Tipografía Estricta: Utiliza el token var(--unav-fontFamilyPrimaryCondensed) con peso Bold y transformación a mayúsculas para priorizar legibilidad.
