Gestión de Cabeceras

Visualización de 66 variantes longitudinales y auditoría visual utilizando inyección de Design Tokens.

Análisis Funcional y Técnico

Este componente sirve como laboratorio de pruebas y catálogo de estilos para las etiquetas <h1> a <h6>. En esta iteración, se integra el uso oficial del componente Etiqueta (.unav-tag) para el marcado de metadatos, cruzando la información topográfica y cromática con nuestro sistema base OOCSS.

  • Generación: Motor JS iterativo que genera las 66 permutaciones.
  • Componente Integrado: Uso de .unav-tag reemplazando estilos hardcodeados.
  • Escala modular: Mapeo directo a los tokens --unav-fontSize500 a --unav-fontSize100.
  • Colores: JS modificado para emparejar la paleta corporativa con la clase modificadora correcta (ej. .unav-tagRojo).
  • Layout OOCSS: Componentizado bajo el bloque .unav-sampleRow.
  • SEO Semántico: Inyección dinámica de itemprop="headline" de Schema.org.
