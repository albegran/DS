Gestión de Cabeceras

Visualización de 66 variantes longitudinales. Cada etiqueta utiliza una de las 11 tipografías con un tamaño y color asignado aleatoriamente de los estándares definidos.

Resumen Técnico y Funcional

Este componente sirve como laboratorio de pruebas y catálogo de estilos para las etiquetas <h1> a <h6>. Demuestra cómo la semántica HTML se desacopla completamente de la presentación visual en nuestro sistema. El script JS iterativo inyecta estilos *inline* simulando cómo las clases de utilidad (tamaños, colores y tipografías corporativas) afectan a cada nivel de jerarquía, facilitando auditorías de legibilidad y coherencia visual en un solo vistazo.

  • Generación: Motor JS iterativo (66 iteraciones).
  • Tipografías base: 11 variantes desde Roboto Thin a DM Serif Text.
  • Escala modular: 11 tamaños predefinidos (de 0.8rem a 4rem).
  • Colores: Arrays vinculados a las variables de color.css.
  • Layout contenedor: Elemento .unav-sampleRow.
  • SEO: Inyección dinámica de itemprop="headline" de Schema.org.
