Design System UNAV

Gestión de Cabeceras

Visualización de 66 variantes longitudinales y auditoría visual utilizando inyección de Design Tokens.

Análisis Funcional y Técnico

Este componente sirve como laboratorio de pruebas y catálogo de estilos para las etiquetas <h1> a <h6>. En esta iteración, se integra el uso oficial del componente Etiqueta (.unav-tag) para el marcado de metadatos y el nuevo cálculo automático de interlineado (Line Height) dependiente del tamaño de fuente, cruzando la información con nuestro sistema base OOCSS.

  • Generación: Motor JS iterativo que genera las 66 permutaciones.
  • Escala modular: Mapeo directo a los tokens de tamaño (--unav-fontSize500 a 100).
  • Interlineado Inteligente: Asignación del token --unav-lineHeight correcto (Tight, Snug o Normal) en función del tamaño del texto.
  • Colores: JS modificado para emparejar la paleta corporativa con la clase modificadora correcta (ej. .unav-tagRojo).
  • Layout OOCSS: Componentizado bajo el bloque .unav-sampleRow.
  • SEO Semántico: Inyección dinámica de itemprop="headline" de Schema.org.
