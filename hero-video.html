Design System UNAV

Hero Vídeo

Cabeceras inmensas (fullwidth) utilizando fondos dinámicos multimedia (YouTube o archivos locales).

Guía Técnica y Documentación Oficial

1. Implementación OOCSS y Estructura

  • Estructura Base: El componente se envuelve en .unav-heroVideo. Requiere el contenedor .unav-videoStage para el reproductor y .unav-heroContent para la capa tipográfica superior.
  • Capa de Contraste: Obligatorio el uso de un .unav-heroOverlay con gradientes oscuros para asegurar que el contenido textual y los botones (CTAs) sean legibles sobre cualquier vídeo.

2. Guía Técnica (JavaScript y API)

  • Integración YouTube: El componente utiliza la API oficial de YouTube (window.unavYtPlayers) para instanciar reproductores. Esto permite controlar mediante botones del sistema (átomos) la reproducción/pausa y el muteo/activación de sonido.
  • Eventos de Control: Los botones de control invocan funciones nativas del sistema (unavToggleYoutubeSound, etc.) que actualizan los iconos (BI Icons) en tiempo real según el estado del player.

3. Accesibilidad (A11y) y Schemas (SEO)

  • A11y (Control de Audio): Es fundamental incluir botones de control con aria-label dinámicos (ej: "Activar sonido" / "Desactivar sonido") para informar al usuario de los cambios de estado.

4. UX, Uso de Átomos y Medios

  • Integración de Átomos: Los controles de reproducción y sonido reutilizan el átomo .unav-botonSecundario .unav-botonIconOnly, manteniendo el tamaño normativo de 32px para la zona de interacción táctil.
  • Medios y Rendimiento: Aunque el vídeo se carga vía API, es vital asegurar que la red esté optimizada. El Hero Vídeo debe tener un comportamiento de carga diferida inicial hasta que el contenedor entra en el viewport.
