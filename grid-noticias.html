Grid de Noticias

Tarjetas de contenido editorial responsivas con microinteracciones delegadas a los Motion Tokens y schema.org integrados.

Guía Técnica y Documentación Oficial

1. Implementación OOCSS y Estructura

  • Retícula Base (Grid): A diferencia del listado continuo, este componente se apoya en la estructura clásica de Bootstrap (.row y .col-*). Para mantener la simetría horizontal de las cajas, es obligatorio aplicar la clase utilitaria .h-100 a cada tarjeta.
  • Reutilización de Componentes: La grilla no define estilos propios de tarjeta, sino que aloja el organismo estándar .unav-card.unav-cardSolid, asegurando una total consistencia transversal en el Design System.

2. Guía Técnica (JavaScript y Motion CSS)

  • Staggering por Fila (JS): El script de IntersectionObserver busca el contenedor padre directo (.row) y calcula el orden de las tarjetas en su interior. El retardo de animación se asigna linealmente multiplicando el índice de la tarjeta por 100ms (index * 100).
  • Transiciones de Estado: Se inicializa la tarjeta con .unav-efectoEntradaOculto, y el observador muta el estado a .unav-efectoEntradaVisible para disparar el efecto de desvanecimiento ascendente (fade-up).

3. Accesibilidad (A11y)

  • A11y y Foco: Si toda la tarjeta es "clicable", se recomienda inyectar un pseudo-elemento en el enlace principal para expandir su área táctil. De lo contrario, los enlaces de "Leer más" deben contener un aria-label o texto oculto especificando el titular de la noticia para no ser genéricos.

4. UX, Integración de Átomos y Layouts

  • Uso de Átomos: Las tarjetas consumen átomos secundarios del sistema para mostrar su metadata: .unav-tag para las categorías y <time> formateado con tipografía de lectura secundaria para las fechas.
  • Gestión de Medios: Las fotografías de cabecera en el grid están controladas por un contenedor de relación de aspecto fija (16:9). Las imágenes deben utilizar el formato WebP con un ancho de carga recomendado no superior a 800px para garantizar un rendimiento óptimo al cargar múltiples columnas simultáneamente.
