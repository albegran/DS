Banner Mini Esquinas Rectas

Componente estructural para Call to Actions con imágenes de fondo o colores sólidos corporativos.

Resumen Técnico y Funcional

Este componente crea un bloque promocional con altura mínima (280px) diseñado para encajar en el grid de Bootstrap. Utiliza un overlay gradiente para garantizar la legibilidad del texto sobre las imágenes e incluye una microinteracción de cinta transportadora en la flecha del enlace.

  • Bloque Principal: .unav-bannerMini
  • Modificadores: .unav-themeDark, .unav-alignCenter
  • Estructura Interna: .unav-bannerMiniOverlay, .unav-bannerContent
  • Dependencias: Requiere el componente .unav-link animado.
  • Restricciones: Obliga border-radius: 0 vía CSS.
  • Marcado SEO: Schema.org WPAdBlock.

1. Variantes con Imagen de Fondo

Usa .unav-themeDark para texto blanco. El overlay oscuro asegura accesibilidad visual.
