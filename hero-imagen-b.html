Componente Hero Imagen B

Visualización de 4 variantes de banners Hero con contenido inyectado (Etiquetas, Título, Entradilla truncada y Botones Primarios).

Resumen Técnico y Funcional

Este componente evoluciona el Hero estándar permitiendo la superposición semántica de contenido textual rico. Incluye un efecto de movimiento sutil por CSS (Ken Burns) que mejora la interactividad sin penalizar el rendimiento. Permite ajustar su layout y altura dinámicamente mediante clases modificadoras.

Truncado de Texto: La entradilla usa -webkit-line-clamp: 3 para limitar visualmente la longitud del texto.

Alturas Modulares: Las clases --short y --half alteran la propiedad aspect-ratio de 21/9 a 21/6 y 21/4.5 respectivamente.

Animación: Efecto CSS infinito unav-slowZoom aplicable opcionalmente con .unav-animacionZoom.

Integración DS: Inclusión directa de componentes .unav-tag y .unav-botonPrimario.

Microdatos (Schema.org): Utiliza WPHeader, asociando headline, description y keywords.

Responsive (Mobile First): En pantallas menores de 768px, todas las variantes colapsan al 100% centrado con ratio 4/5 para máxima legibilidad.
