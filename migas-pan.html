Design System UNAV

Migas de Pan (Breadcrumbs)

Componente de navigation secundaria para ubicar jerárquicamente la página actual dentro del árbol del sitio web.

Análisis y Documentación Oficial

1.- Guía de Implementación y Modificadores

Uso de clase OOCSS: El componente se envuelve en una etiqueta <nav> y utiliza la clase estructural .unav-breadcrumbs aplicada de forma directa sobre una lista ordenada <ol>.

Modificadores de Estado: El nivel correspondiente a la página activa debe llevar la clase de ítem activa y el texto final formateado, el cual inhabilita las acciones de clic.

2.- Guía Técnica

Geometría Responsiva Líquida: El sistema inyecta propiedades de desbordamiento horizontal (overflow-x: auto) combinadas con flex-wrap: nowrap. Esto asegura que en resoluciones móviles el componente mantenga una sola línea deslizable de forma táctil.

Separación por Pseudo-elementos: Los iconos de flecha chevrón se inyectan de forma limpia mediante la regla CSS ::before y tipografía icónica, evitando la inserción de nodos redundantes en el HTML.

3.- Accesibilidad (A11y)

Atributos Semánticos WCAG: La etiqueta contenedora <nav> debe portar de forma obligatoria un atributo descriptivo aria-label="Breadcrumb". Adicionalmente, el ítem activo final no debe ser cliqueable.

4.- UX, Layout y Medios

Control de Textos Extensos: Para evitar roturas en los contenedores ante nombres de facultades o asignaturas masivas, el sistema integra la clase utilitaria de truncado (max-width: 200px, text-overflow: ellipsis) que aplica puntos suspensivos automáticamente.

Uso de Tipografía: Renderiza consumiendo el tamaño meta atómico --unav-fontSize075 (12px) o 0.875rem con interlineado de bloque --unav-lineHeightNone (1), eliminando márgenes parasitarios.
